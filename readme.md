# Tic Tac Toe
A two-player tic-tac-toe game that runs in the browser. No build step or install.
## Play
Open `index.html` in a browser, or from this folder:
```bash
# Windows
start index.html
```
X goes first. Click a square to place a mark. The first player to get three in a row wins. Scores stay until you refresh the page.
## Files
- `index.html` — page layout
- `styles.css` — layout and colors
- `script.js` — turns, win/draw checks, scores
